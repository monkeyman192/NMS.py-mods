# Mod Menu

This mod adds two extra items to the mod menu - "Mods" and "NMS.py Mods".
These menus are both available from both the in-game menu and the options menus.

**Important**: If you disable the `ModManager` mod from the NMS.py mod menu you will disable the mod itself. There is a failsafe to return up back to the options menu so that you don't get softlocked, but you won't be able to re-enable this menu unless you exit the game and restart, or re-enable the mod via the pyMHF gui popup separate from the game window.
If you have that window disabled then you will need to restart the game to get the mod back.
